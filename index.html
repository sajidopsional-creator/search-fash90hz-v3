ⓘ INFO PENTING

Beberapa website tidak bisa ditampilkan langsung di Fash90Hz karena pemilik website membatasi akses melalui iframe. Hal ini tidak selalu berarti website sedang rusak.

Cara membuka website di browser lain

  1. Pilih website yang ingin dibuka.
  2. Masuk ke tab BROWSER.
  3. Tekan tombol ↗ di sebelah kolom alamat.
  4. Website akan dibuka melalui browser perangkat.
  5. Pilih Chrome atau browser lain jika diminta.

Tips: Jika halaman putih atau kosong, gunakan tombol ↗.
